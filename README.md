# Estimation & Detection Theory

Monte Carlo experiments comparing classical and Bayesian estimators.
Course project for *Detection and Estimation Theory*, Aristotle University of Thessaloniki (2024).

## What it does
| Script | Topic |
|---|---|
| `thema1.m` | Maximum-likelihood (MLE) vs. minimum-variance unbiased (MVUE) estimators for an exponential distribution, compared against the Cramér–Rao lower bound for increasing sample sizes |
| `thema2.m` | Bayesian MMSE estimation under normal, uniform and exponential priors, compared with the classical estimate |
| `thema3.m` | Identifying the underlying distribution of a dataset (exponential vs. Rayleigh) from `data.mat` |

## Tools
MATLAB (random sampling, Monte Carlo simulation, histograms)

## How to run
Open MATLAB in this folder and run `thema1.m`, `thema2.m` or `thema3.m`.
